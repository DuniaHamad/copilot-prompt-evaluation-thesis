# Copilot Prompt Evaluation Thesis

## Projektübersicht

Dieses Projekt ist Teil meiner Bachelorarbeit und beschäftigt sich mit der **Analyse der Leistungsfähigkeit von GitHub Copilot** bei der Bearbeitung von Programmieraufgaben von der Plattform [LeetCode](https://leetcode.com/).  
Ziel ist es, zu untersuchen, wie sich **unterschiedliche Prompt-Formulierungen** auf die **Qualität, Effizienz und Konsistenz** der von Copilot generierten Lösungen auswirken.  

Darüber hinaus soll ein **Framework für die strukturierte Nutzung von GitHub Copilot** entwickelt werden, das Entwicklerteams helfen kann, Aufgaben präzise zu spezifizieren und dadurch qualitativ hochwertigen Code schneller zu erzeugen.

---

## Projektziele

- Auswahl von **50 Programmieraufgaben** aus LeetCode, ausschließlich in **TypeScript**  
- Zweifache **Prompt-Formulierung** pro Aufgabe (detailliert vs. kurz)  
- **Kategorisierung nach Schwierigkeitsgrad** (leicht, mittel, schwer)  
- **Erhebung quantitativer Metriken** (Zeit bis zur Lösung, Iterationsanzahl, Codezeilenanzahl)  
- **Qualitative Bewertung** der Lösungsqualität anhand festgelegter Kriterien  
- **Entwicklung eines theoretisch fundierten Frameworks**, das iterativ optimiert wird  

---

## Vorgehensweise

1. **Aufgabenauswahl**  
   - Auswahl von 50 LeetCode-Problemen in TypeScript  
   - Fokus auf algorithmische und datenstrukturelle Aufgaben  

2. **Prompt-Formulierung**  
   - **Detailliert:** exakte Definition mit Beispielen und Randbedingungen  
   - **Kurz:** knappe Beschreibung ohne Zusatzdetails  
   - Formulierungen mithilfe von **ChatGPT** basierend auf LeetCode-Daten  

3. **Testdurchführung**  
   - Verwendung von **Visual Studio Code** mit GitHub Copilot **(Version 1.336.0)**  
   - Erfassung der generierten Lösungen beider Promptvarianten  

4. **LeetCode-Auswertung**  
   - Einreichung jeder Copilot-Lösung auf LeetCode  
   - Dokumentation von Korrekturen und Wiederholungen bis zur finalen Lösung  
   - Vergleich der Erfolgsraten zwischen kurzer und detaillierter Formulierung  

5. **Dokumentation und Metriken**  
   - **Iterationsanzahl**, **Zeitaufwand**, **Codezeilenanzahl**  
   - Strukturierte Auswertung in **Excel** 

6. **Qualitative Bewertung**  
   - Skalen für **Lesbarkeit**, **Effizienz** und **Wartbarkeit**  
   - Konsistente Beurteilung mit Unterstützung durch **ChatGPT**  

7. **Datenanalyse**  
   - Vergleich von Effizienz und Qualität zwischen beiden Promptarten  
   - Analyse des Einflusses von Formulierungsart  

8. **Framework-Entwicklung**  
   - Ableitung von **Best Practices** für Prompt-Formulierungen  
   - Aufbau eines **strukturierten Frameworks** zur Unterstützung von Entwicklerteams  
   - Iterative Optimierung während der Experimentphase
